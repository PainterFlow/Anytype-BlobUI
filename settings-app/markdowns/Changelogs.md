# BlobUI v1.6.0 - What's new?

Welcome to BlobUI v1.6.0, yes it may be small, but also kinda big as we are finally adding the long awaited MacOS support.
Additionally there are also some other features that have just been awaiting implementation.

## General

- BlobUI, Anyblob and BlobUI CLI now all support MacOS.
- In Advanced Settings -> App Settings you can now toggle whether you want to enable streamer mode, this will hide Anytype from screencapture software
- The onboarding has now been remade.

## Anyblob (v1.3.0 -> v1.4.0)

- Now supports MacOS.

## BlobUI Headless CLI (v1.1.0)

- Now supports MacOS.

## Developer Changelogs

- Added MacOS versions of all scripts & test scripts.
