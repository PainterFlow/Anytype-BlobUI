# BlobUI v1.6.0 - What's new?

BlobUI v1.6.0 is finally introducing the long awaited MacOS support, alongside with some other long awaited features.
In addition to that I have remade big parts of the UI with windowed mode being experimental right now.

## General

### Features

- BlobUI, Anyblob and BlobUI CLI now all support MacOS.
- In Advanced Settings -> App Settings you can now toggle whether you want to enable streamer mode, this will hide Anytype from screencapture software

### UI & Documentation Improvements

- Added documentation for kanban view calculations in the kanban view calculation child tab.
- The onboarding experience and UI has now been remade.
- Massive parts of the UI have been remade.

## Anyblob (v1.3.0 -> v1.4.0)

- Now supports MacOS.

## BlobUI Headless CLI (v1.1.0)

- Now supports MacOS.

## Developer Changelogs

- Added MacOS versions of all scripts & test scripts.
- Added dev docs for making your own custom theme in the section for custom themes under the preferences tab.

### UI Improvements

- Added re-usable checkmark type.
- Added new button style that has no button shape until hovered, with the disabled variant just having darker text/icons.
- Added new re-usable preview card UI element that is only used in onboarding right now.
- List views are now generalised and detached from kanban views.
- List views have a lot more capabilities.
- Selections have been remade in the backend.
- Added Icons to a variety of elements.
- New Advanced Selector UI element.  
- Moved more UI to ReactJS.
