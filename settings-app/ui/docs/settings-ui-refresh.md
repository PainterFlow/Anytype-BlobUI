# Settings UI

Settings uses category tabs and expandable sidebar navigation. The screenshot shows Preferences tabs and the Space banner page.

![Refreshed Settings with Preferences tabs and a Space banner preview](@settings-ui-refresh)

## Preferences and navigation

Preferences uses Accent, Kanban, Calendar, Typography, and Space banner tabs. Section links appear below Preferences and Advanced Settings in the sidebar. Category navigation can be expanded or collapsed. Accessibility remains a single page.

Advanced Settings contains API key and App settings tabs. Tab controls support arrow keys, Home, and End. Switching tabs resets the panel to the top and keeps pending edits. Opening another Settings page does not save those edits.

Kanban View Formulas opens from a button under Preferences > Kanban. The view browser keeps its own search and space filter. Ordinary Settings pages do not gain search fields.
