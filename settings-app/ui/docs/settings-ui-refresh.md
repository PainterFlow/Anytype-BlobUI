# Settings UI

Settings uses category tabs and expandable sidebar navigation. The screenshot shows Preferences tabs and the Space banner page.

![Refreshed Settings with Preferences tabs and a Space banner preview](@settings-ui-refresh)

## Preferences and navigation

Preferences uses Colors, Font, and Space banner tabs. Calendar Events and Kanban Views appear below Accessibility, in that order, and each has Appearance plus a feature-specific child tab. Section links appear below Preferences, Calendar Events, Kanban Views, and Advanced Settings in the sidebar. Category navigation can be expanded or collapsed. Accessibility remains a single page.

Advanced Settings contains API key, App settings and Experiments tabs. Tab controls support arrow keys, Home, and End. Switching tabs resets the panel to the top and keeps pending edits. Opening another Settings page does not save those edits.

Integrations contains Anyblob with Settings, Permissions, and Projects sections. Read [Anyblob Configuration](https://github.com/PainterFlow/Anytype-BlobUI/blob/dev/settings-app/ui/docs/anyblob-configuration.md) for the access controls.

Kanban View Formulas appears under Kanban Views > Kanban Calculations. The view browser keeps its own search and space filter. Ordinary Settings pages do not gain search fields.
