# Settings UI

Settings Future Proof UI Refresh changes how you move through Settings. The screenshot shows Preferences tabs and the Space banner page.

![Refreshed Settings with Preferences tabs and a Space banner preview](@settings-ui-refresh)

## Preferences and navigation

Preferences uses Accent, Kanban, Calendar, Typography, and Space banner tabs. Section links appear below Preferences and Advanced Settings in the sidebar. Category navigation can be expanded or collapsed. Accessibility remains a single page.

Advanced Settings contains API key, App settings, and Experiments tabs. Tab controls support arrow keys, Home, and End. Switching tabs resets the panel to the top and keeps pending edits. Opening another Settings page does not save those edits.

Kanban View Formulas moves from its original sidebar entry to a button under Preferences > Kanban. The view browser keeps its own search and space filter. Ordinary Settings pages do not gain search fields.

## Return to the original layout

Turn off Settings Future Proof UI Refresh under Advanced Settings > Experiments, then select Save. Both layouts use the same settings and drafts, including your fonts, accent, API connection, and saved appearance choices.
