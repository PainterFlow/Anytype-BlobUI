Leave the port blank to use 31009.

Create an API key

  1. Open Anytype’s settings and choose Local API.
  2. Turn on Enabled. Keep the port at 31009, or enter your custom port above.
  3. Click Create new and name the app BlobUI.
  4. Choose the spaces BlobUI can read. Select Allow access to all spaces for features across your workspace.
  5. Set Access to Read only and Expires to Never.
  6. Click Create key, copy the API v2 key, and paste it above.

Your key stays on this computer, encrypted for your Windows account. BlobUI only reads the spaces you allow.
