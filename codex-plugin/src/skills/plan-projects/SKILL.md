# Plan projects

Before using tools, read [Anyblob workflow rules](../../references/workflow-rules.md) for permissions, creation, mutation recovery and verification.

Read relevant permitted project content and search for existing tasks. Inspect the live task type, properties, options and templates. Draft tasks with concrete outcomes and completion criteria. Reuse existing priority values and dependency or project properties. If no dependency property exists, use links in task content. Do not invent owners or deadlines.

A request for a plan alone does not authorize task creation. When creation is requested, follow the shared creation procedure. Record each confirmed task ID before linking dependents. Link only confirmed IDs. Report partial completion if later tasks or links fail. Resume from confirmed receipts rather than recreating tasks. Return task links, dependency order and completion criteria.
