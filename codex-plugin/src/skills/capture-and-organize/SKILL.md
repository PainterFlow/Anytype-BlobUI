# Capture and organize

Before using tools, read [Anyblob workflow rules](../../references/workflow-rules.md) for permissions, creation, mutation recovery and verification.

Identify distinct objects from the notes without inventing facts. Search for existing objects before creating duplicates. Inspect list_types, get_type, list_properties, list_property_options and list_templates as needed. Reuse live keys, options and templates. Leave uncertain dates, owners and classifications unset unless required.

Suggest placement when asked for advice. Create only when requested, using the shared creation procedure. Preserve source links. Report created object links, placement results and unresolved choices. Do not change query definitions or add unrelated existing collection members merely to place a new object.
